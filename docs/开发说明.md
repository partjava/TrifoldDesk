# 开发说明

项目使用 C#、WPF 和 .NET 8，分为界面应用、核心逻辑与核心检查三个项目。Windows目标框架为net8.0-windows10.0.19041.0，依赖Windows SDK引用与LibreHardwareMonitorLib 0.9.6；NuGet.Config使用官方NuGet源。

## 构建验证

在 Windows 上执行 `Build.ps1 -Test -Version '0.10.17'`。核心检查失败时停止发布；窗口自测使用独立数据目录，报告位于本地 verification 目录，不写入正式用户配置。发布产物位于 dist，均不纳入源码仓库。`BuildInstaller.ps1 -Version '0.10.17'`生成内置.NET运行环境的Windows x64安装包，需要Inno Setup。

## 布局和数据

组件属于左、中、右某个页面，移动和调整大小后需限制在所属页面边界内。页面折叠独立控制。图标按网格槽位保存，允许空槽，不能用连续排序覆盖用户保留的空位。独立图标与文件夹内入口之间移动时，应同时更新归属和位置。

用户配置放在 AppData，使用 JSON、原子写入和备份恢复。不要提交正式配置、应用快捷方式缓存、日志或带有个人文件路径的截图。

## 新增模块

ProfilePackage负责配置包与资源重定位；ConfigTransaction以持久日志保证多文件更新恢复；LegacyPluginMigration保留原入口并转换旧组件；FolderWorkspace负责嵌套、映射与历史；CalendarEvents负责重复日程、提醒去重和带来源的调休；ScriptLaunch保留参数边界，不通过命令拼接执行脚本。

后台服务包括共享GPU/硬件采样、Open-Meteo缓存、只读Git查询、系统媒体与无线电接口。进程插件通过哈希授权，导入配置不迁移授权；UTF-8数据协议有输出限制与45秒超时，卸载时结束进程树。

折叠使用Viewport3D和真实铰链旋转，仅在动画期间保留截图。Explorer宿主可选启用并安全回退；monitors.json保存各显示器的组件布局。

## 后续验证与明确限制

- 传感器接口已接入；继续验证设备/权限覆盖范围，缺少驱动或硬件支持时明确不可用。
- 验证 Win+D、Explorer 重启、多显示器变化与注销后自启动。
- 对真实鼠标拖放、边缘停留扩展、拖出为独立图标进行持续交互验证。
- v1插件仅支持文字数据；任意UI插件、权限沙箱和同时多屏桌面仍未实现。
- 无线权限、媒体播放器兼容性、首次高清图标提取及长期资源占用需要持续实际验证。

## 扩展回归探针

从仓库根目录执行以下命令。探针只使用`.test-data`内的独立配置与临时文件；不会开关Wi-Fi/蓝牙，不执行用户插件，不修改正式布局。桌面宿主探针挂载临时窗口并恢复其父级。

```powershell
dotnet run --project tests/TrifoldDesk.FolderProbe
dotnet build tests/TrifoldDesk.PluginProbeWorker
dotnet run --project tests/TrifoldDesk.RuntimeProbe
```

文件夹探针验证嵌套/返回/撤销、目录变更刷新、拖出引用与建组。进程探针验证授权、中文UTF-8、输出限制、EOF不冻结和卸载退出；配置替换探针验证便签保存失败保留文本、旧天气/便签不写回新配置。硬件、媒体、无线与Explorer接口仍需实际环境验收，接口不可用并不等于对应设备可用功能已通过。
