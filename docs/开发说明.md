# 开发说明

项目使用 C#、WPF 和 .NET 8，分为界面应用、核心逻辑与核心检查三个项目。无需第三方 NuGet 包；NuGet.Config 清空了外部包源。

## 构建验证

在 Windows 上执行 `Build.ps1 -Test -Version '0.10.9'`。核心检查失败时停止发布；窗口自测使用独立数据目录，报告位于本地 verification 目录，不写入正式用户配置。发布产物位于 dist，均不纳入源码仓库。

## 布局和数据

组件属于左、中、右某个页面，移动和调整大小后需限制在所属页面边界内。页面折叠独立控制。图标按网格槽位保存，允许空槽，不能用连续排序覆盖用户保留的空位。独立图标与文件夹内入口之间移动时，应同时更新归属和位置。

用户配置放在 AppData，使用 JSON、原子写入和备份恢复。不要提交正式配置、应用快捷方式缓存、日志或带有个人文件路径的截图。
