# 功能状态 · 0.10.17

本表描述源码当前实现，公开 Release 是否更新请以仓库发布页为准。新增组件均按需添加，设置和管理操作集中在右键菜单。

| 类别 | 已实现 | 边界与后续验证 |
| --- | --- | --- |
| 组件精简与预览 | 插件库九种静态预览；单项监控合并为系统概览；旧应用/资料分组迁移为普通文件夹，保留入口 | 旧类型只保留兼容读取，不再提供新建入口；移除组件不会删除原文件 |
| 配置备份与迁移 | ZIP导出、完整导入预览、图标/生成快捷方式/插件资源、原目录整体备份、事务恢复、版本升级与未来版本保护 | 外部文档只保存路径；跨电脑需重新定位外部文件；第三方插件导入后重新授权 |
| 启动诊断 | 设置可查看真实配置目录、程序版本、布局/入口数量、缺失路径、读取警告及桌面宿主状态 | 诊断含本机路径，公开反馈前应检查 |
| 文件夹 | 图标叠放建组、稀疏网格、嵌套与返回、目录映射与文件变化刷新、会话内20步撤销重做、拖出独立图标、四角缩放 | 映射目录浏览前512项；拖出创建引用；不移动真实文件；历史不跨重启 |
| 组件避让 | 拖动或缩放后寻找同页最近可容纳位置，保持页面边界 | 页面无足够空位时提示并保留位置；尚无实时避让预览 |
| 图标 | 按DPI提取Shell高清图标，去快捷方式箭头，文件修改后缓存失效，512项缓存上限 | 首次提取仍在调用线程；大量图标长期内存和鼠标操作继续验收 |
| 日历 | 农历、倒计时/纪念日、日程编辑、每周/每年重复、周历、提前提醒与投递去重 | 提醒依赖应用运行；系统可能屏蔽托盘提醒；闰日年度重复跳过非闰年 |
| 节假日 | 内置经官方通知核实的2026年安排，支持带来源的JSON导入 | 未提供年份明确显示缺失，不预测调休；[官方来源](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html) |
| 硬件 | 共享CPU/内存/网络/GPU采样；按DXGI显卡标识选择3D引擎；显存、温度、风扇传感器详情 | 温度/风扇取决于设备；CPU/主板低层数据可能需要管理员权限及已安装PawnIO，本程序不安装驱动；不可用时不补假数据 |
| 便签与待办 | 工作台保存便签、待办完成/归档/恢复 | 独立组件按需添加，数据随配置包备份 |
| 天气 | 选城市后查询Open-Meteo，30分钟节流、缓存和错误提示 | 需要网络；不自动读取定位；缓存明确显示更新时间 |
| 音乐 | 系统媒体会话、播放/暂停、上一首/下一首及会话事件更新 | 播放器必须提供Windows媒体会话；接口权限不足时显示原因 |
| 文件树与Git | 真实目录懒加载、最多500项、只读Git状态查询及超时控制 | Git需在PATH中；不修改索引；不递归目录链接 |
| 系统控制 | Wi-Fi/蓝牙无线电状态、用户操作切换、蓝牙设备列表、系统设置入口 | 权限和系统策略可能拒绝切换；当前Wi-Fi连接信息可能受应用身份限制；飞行模式仍打开Windows设置 |
| 桌面宿主 | 可选Explorer WorkerW挂载，验证父级、失败还原，接收Explorer重启消息 | 使用系统内部接口；不同Windows/DPI模式可能回退；Win+D与Explorer重启需实际系统验收 |
| 三维折叠 | 使用Viewport3D、纹理截图和真实铰链旋转；结束后释放截图 | 仅动画期间绘制；没有常驻三维场景 |
| 多屏布局 | 各显示器保存独立组件布局，切换后加载，保留离线显示器记录 | 当前一套桌面显示在选中的屏幕上；尚未同时在多个屏幕各运行一套；文件夹内容和独立图标数据共享 |
| 第三方插件 | v1清单导入、独立进程、UTF-8数据行、文件哈希授权、错误/超时/卸载终止 | 目前支持文字数据，无任意UI或DLL加载；进程隔离不限制用户权限，详见[协议](插件协议.md) |
| 脚本启动 | 默认关联、明确Python解释器、PowerShell、指定程序、独立参数与工作目录 | 保存不执行；用户需自行安装解释器；不绕过系统执行策略 |

性能策略保留：圆环共享时钟与动画开关、电池降频、不可见/单窗口完全遮挡暂停绘制、GPU共享缓存、磁盘30秒读取、异常日志限频。多窗口拼接遮挡与透明覆盖层尚未精确判断。新版新增功能的持续性能收益应另作实测，不能沿用上一版本短测结论。
