# TrifoldDesk 插件协议 v1

插件以独立进程运行。当前协议支持文字与数据行，不能把任意 DLL 加载到主程序，也不是限制文件/网络权限的安全沙箱。

在插件库选择“导入插件”，选择包含 manifest.json 的目录。添加组件后，右键“允许启动插件”。配置导入不会首次自动授权插件；包内文件变化会使授权失效。请只启用可信来源。

manifest.json 示例：
```json
{"apiVersion":1,"id":"sample-status","name":"示例状态","version":"1.0","executable":"Worker.exe","arguments":[],"capabilities":["读取本机状态"]}
```

Worker.exe 必须在目录内。可包含依赖 DLL，但不允许目录链接；单文件最大32MB，总128MB，最多512文件。插件需要自行满足运行环境。

stdin 和 stdout 必须使用 UTF-8。宿主向 stdin 写入 `{"apiVersion":1,"type":"init"}`。插件向 stdout 每行输出一条JSON，如：
```json
{"title":"示例状态","lines":["采样完成","下一次更新：30秒后"]}
```

属性大小写不敏感。标题最多200字，最多32行，每行1000字，消息最大16KB。至少每45秒发出一次快照；超时、协议错误或退出会停止插件。不要把日志写 stdout，可使用 stderr（宿主丢弃日志防止重复写盘）。插件移除/组件卸载会停止进程树，崩溃不会结束主程序。

.NET 控制台生产者示例：
```csharp
using System.Text.Json;
Console.InputEncoding = new System.Text.UTF8Encoding(false);
Console.OutputEncoding = new System.Text.UTF8Encoding(false);
Console.ReadLine();
while(true){Console.WriteLine(JsonSerializer.Serialize(new{title="我的状态",lines=new[]{DateTime.Now.ToString("HH:mm:ss")}}));await Task.Delay(30000);}
```
发布为Windows程序，将产物及清单放在同一目录。不要依赖主程序的 DLL。需有相应.NET运行时或自行发布独立程序。
