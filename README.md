# TrifoldDesk · 三折桌面

Windows 桌面整理工具：用左、中、右三个可独立折叠的页面，放置应用、文件夹和按需添加的小部件。

![TrifoldDesk 桌面效果](home.png)

## 功能

- **三页布局**：独立折叠，组件拖动后归属最近的页面，并限制在页面边界内。
- **桌面文件夹**：拖入文件、目录和快捷方式；固定网格自由排序、保留空位、跨文件夹移动，支持四角调整大小和竖向滚动。
- **独立图标**：将入口拖出文件夹，放在当前页面空白处；也可拖回文件夹。停留在文件夹边缘可逐步扩展显示区域。
- **应用选择**：从已安装应用中搜索、选择并添加入口，保留启动参数，区分不同安装环境。
- **组合监控**：CPU、内存、GPU 3D、网速、电池和各磁盘容量，可选择显示内容和显卡；旧单项组件统一迁移到概览。
- **文件夹工作区**：图标叠放建组、嵌套分组、真实目录映射和会话内撤销重做；映射目录拖出仅创建入口。
- **组件预览**：添加前查看九种内置组件的静态示例；便签/待办、天气、系统媒体、文件树与只读Git均按需添加。
- **配置管理**：完整配置包导出/导入、旧目录整体备份、未来版本保护；启动诊断显示真实目录和缺失路径。
- **日历与日期计算**：月历、农历提示、月份切换，以及自定义倒计时和已过去天数。
- **按需添加**：时钟、日历、监控和系统控制等内置组件可自行选择；支持拖动、缩放、锁定和移除。
- **桌面运行**：默认保持在普通窗口下方，提供托盘入口和开机登录自启动设置。

操作集中在右键菜单，桌面仅保留内容与必要的控件。

## 下载运行

[下载 Windows x64 中文安装包](https://github.com/partjava/TrifoldDesk/releases/latest)。下载 Setup EXE 后双击，按向导选择安装位置。安装版内置运行环境，无需单独安装 .NET；支持开始菜单、可选桌面快捷方式、开机自启动与卸载。旧版 ZIP 免安装包仍需 .NET 8 Windows Desktop Runtime。

## 从源码构建

当前源码版本为 **0.10.17**。适用于 Windows 10 2004（19041）及更新版本、Windows 11 x64。公开安装包以发布页为准。

安装 .NET 8 SDK，或具备 .NET 8 目标框架支持的更新 SDK，然后在项目根目录打开 PowerShell：

```powershell
git clone https://github.com/partjava/TrifoldDesk.git
cd TrifoldDesk
.\Build.ps1 -Test -Version '0.10.17'
.\启动三折桌面.bat
```

构建结果位于 `dist/v0.10.17/`。运行需要 **.NET 8 Windows Desktop Runtime x64**，请保留整个发布目录，不能只复制 EXE。首次构建需联网恢复Windows SDK和LibreHardwareMonitor依赖。

## 使用

| 操作 | 方法 |
| --- | --- |
| 添加组件、管理入口、设置 | 桌面空白处右键 |
| 折叠或展开某页 | 空白处右键，选择左、中、右页 |
| 添加文件或应用 | 拖入文件夹，或在文件夹空白处右键添加 |
| 移动图标 | 拖到目标网格；空位会保留 |
| 调整组件大小 | 拖动组件四角 |
| 添加倒计时或纪念日 | 日历右键 → 添加日期 |
| 修改日期事件 | 点击事件，或右键编辑、删除 |
| 设置自启动 | 托盘或桌面右键进入设置 |
| 退出 | 托盘菜单 → 退出；Alt+F4 会收起桌面 |

移除入口不会删除原文件；移除组件会保留应用和资料入口数据。

## 数据保存

配置保存在 `%APPDATA%\TrifoldDesk`。设置可导出完整配置包，包含生成快捷方式、图标和插件资源；导入前预览并备份整个原目录。外部个人文件只保存路径。未来版本数据受到只读保护。仓库不包含个人配置、应用列表和日志。

## 隐私与联网

当前主程序没有配置遥测、广告或个人配置自动上传。天气组件在用户选择城市后向 Open-Meteo 发送城市查询词或城市经纬度；服务端也会收到网络请求的 IP 地址。第三方插件、脚本和打开的外部程序有各自的联网行为，不受本项目控制。

导出的配置包可能包含本机路径、应用入口、便签、待办、日程和插件资源；诊断与日志也可能包含个人信息。分享前请检查并脱敏，不要将完整配置包公开上传到 Issue。

## 升级与卸载

升级前建议在设置中导出配置包，再使用官方 Release 安装包安装到原目录。卸载通过 Windows“已安装的应用”或开始菜单的卸载入口进行；个人配置目录会保留，确认不再需要且已备份后，可自行删除 `%APPDATA%\TrifoldDesk`。自定义数据目录需另行处理。

## 后续更新计划

以下四项仍待完善，列入后续更新；当前版本不承诺已完成或在所有设备上可用。

1. **多屏同时运行**：目前支持各显示器独立保存、切换布局；后续完善多个屏幕同时各自显示一套桌面。
2. **直接切换飞行模式**：当前入口打开 Windows 设置；后续研究系统允许的直接切换方式。
3. **桌面宿主嵌入**：已有可选 Explorer 宿主和失败回退；本机测试发生回退，后续继续验证不同 Windows/DPI 环境、Win+D 和资源管理器重启。
4. **温度与风扇兼容性**：数据受硬件、驱动及权限支持限制；后续扩大支持范围，不支持时显示不可用，不生成模拟数据。

更新进度以发布说明和[功能状态](docs/功能状态.md)为准。

## 当前限制与验证边界

- 第三方插件v1支持独立进程文字数据，尚不支持任意UI；独立进程不是权限沙箱，见[插件协议](docs/插件协议.md)。
- 温度、风扇和显存取决于设备与权限；缺少数据明确显示不可用，本程序不安装底层驱动。GPU使用率来自选定显卡的3D引擎。
- 磁盘条显示逻辑卷容量；开机自启动指用户登录后的启动。
- 桌面底层模式仍需验证 Win+D、资源管理器重启及真实注销后自启动的行为。
- 文件拖动的速度区分、边缘扩展与跨文件夹交互仍需更多实际鼠标操作验证。
- 日程提醒依赖应用运行；系统可能屏蔽托盘提醒。内置经官方核实的2026年调休安排，其他年份需导入有效数据。
- 无线切换受系统授权限制；飞行模式仍打开Windows设置。媒体功能要求播放器提供系统媒体会话。
- 多屏布局可独立保存和切换，目前尚未同时在多个屏幕各运行一套；Explorer宿主使用内部接口，不兼容时回退。

完整实现范围、性能策略与验证边界见[功能状态](docs/功能状态.md)。

## 项目结构

```text
src/TrifoldDesk.App/      WPF 界面、Windows 集成与组件
src/TrifoldDesk.Core/     配置、布局与入口逻辑
tests/TrifoldDesk.Tests/  核心检查
Build.ps1                构建和窗口自测
AutoStart.vbs            自启动入口
home.png                 桌面效果图
```

`Build.ps1 -Test` 会执行核心检查与独立数据目录下的窗口自测。更多说明见 [开发说明](docs/开发说明.md)。

## 构建安装包

安装 Inno Setup 6.7 或更新版本后，运行 BuildInstaller.ps1 -CompilerPath '你的 ISCC.exe 路径'。脚本发布 Windows x64 自包含程序，并编译 installer/TrifoldDesk.iss；需要访问官方 NuGet 包源。输出在 dist/installers。
